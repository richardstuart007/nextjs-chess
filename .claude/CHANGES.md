# Changes — nextjs-chess, "version": "1.0.4"

## src/app/api/cron/sync/route.ts
- Added Postgres advisory lock (`pg_try_advisory_lock(1)`) at the start of the cron
- If another invocation is already running, returns immediately with "Sync already running, skipping"
- Prevents concurrent Vercel cron instances from racing to insert the same games

## scripts/schema.sql
- Converted all `SERIAL PRIMARY KEY` columns to `INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
- Updated `tplr_player_ratings.plr_plrid` from plain `INTEGER PRIMARY KEY` to `INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` to match the live database
